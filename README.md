# Tabs Manager

This Chrome/Edge extension manages and stores browser tabs and their relative URLs using omnibox commands in the address bar.

To use it, type 'tab' and press TAB to enter a command, then select a suggestion:
```
Command               Usage
goto:regex            Highlight open tabs filtered by a regex
save:regex            Store open tabs filtered by a regex
close:regex           Close open tabs filtered by a regex
mute:regex            Mute/unmute open tabs filtered by a regex
pin:regex             Pin/unpin open tabs filtered by a regex
reload:regex          Reload open tabs filtered by a regex
duplicate:regex       Duplicate open tabs filtered by a regex
open:regex            Open stored tabs filtered by a regex
delete:regex          Delete stored tabs filtered by a regex
export:regex          Export stored tabs
```
